## 👋 About Me

I'm **Raman Kumar Sharma**, an application engineer and product builder focused on resilient applications, multi-service ecosystems, and AI agent execution systems.

My work spans **cross-platform mobile development with Flutter**, **web applications with React and TypeScript**, backend integrations, and **agentic AI using the Model Context Protocol (MCP)**. I care about what happens beyond the happy path: dependable state transitions, secure tool execution, responsive interfaces, and systems that behave predictably in real-world use.

- 🧩 **Application architecture:** coordinated clients, APIs, data contracts, and operational workflows
- 📱 **Cross-platform engineering:** Flutter and Dart applications with reactive state management
- 🌐 **Web engineering:** React, TypeScript, responsive interfaces, and performance-focused delivery
- 🤖 **Agentic systems:** MCP, JSON-RPC, tool execution policies, and execution telemetry
- 🔐 **Engineering priorities:** reliability, security boundaries, maintainability, and measurable behavior
- 📍 **Current focus:** building production-oriented products and dependable AI-enabled workflows

## 🧠 How I Approach Engineering

- **Architecture before syntax:** define boundaries, contracts, and state transitions before adding complexity.
- **Deterministic agent execution:** explicit tool schemas, authorization policies, isolation, and traceable results.
- **One source of truth:** synchronize multi-role interfaces around consistent data and lifecycle rules.
- **Performance with purpose:** optimize startup, rendering, responsiveness, and real user workflows—not just benchmark numbers.
