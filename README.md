## A little about me

I'm **Raman Kumar Sharma**, also known as **ALEX**. I work across **Flutter, Dart, React, and TypeScript**, building mobile applications, web experiences, and tools for developers.

I enjoy the full product-building process: understanding a problem, shaping the experience, implementing the application, integrating services, and refining the details that make software reliable and pleasant to use.

- 📱 **App development** — Flutter and Dart
- 🌐 **Web development** — React, TypeScript, JavaScript, and Vite
- 🔥 **Backend & data** — Firebase, Firestore, REST APIs, and SQLite
- 📦 **Open source** — Dart/Flutter packages, reusable tooling, and documentation
